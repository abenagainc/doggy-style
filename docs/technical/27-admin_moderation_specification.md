Document 27 — Admin & Moderation Specification

Doggy Style — Operational Back Office


## 1. Admin Areas

- User management.

- Dog management.

- Verification review.

- Reports.

- Moderation cases.

- Blocks/safety events.

- Matching configuration.

- Operational dashboard.


## 2. Report Workflow

- Report submitted → case created → triage → investigation → action/no action → case closed.

- Case history should be auditable.


## 3. Moderation Actions

- Warn, restrict, suspend, ban, remove content, reject verification, approve verification, reinstate.

- Exact enforcement policy can be configured without changing the core product model.


## 4. Verification Review

- Reviewer sees submitted evidence and the minimum relevant account/dog context.

- Reviewer records decision and timestamp.


## 5. Administrative Security

- Admin access requires elevated authentication and role authorization.

- Sensitive actions should be auditable.
