Document 26 — Verification & Trust Specification

Doggy Style — Tiered Trust Model


## 1. Verification Tiers

- Tier 1 — Verified Owner.

- Tier 2 — Verified Dog.

- Tier 3 — Verified Health / Pedigree.


## 2. Owner Verification

- Confirms the human account according to the chosen verification process.

- Status: Not Started, Pending, Approved, Rejected, Needs Update/Expired where applicable.


## 3. Dog Verification

- Confirms the dog/ownership relationship according to the selected evidence process.

- Verification status is displayed on relevant profile and discovery surfaces.


## 4. Health / Pedigree

- Evidence may be submitted and reviewed.

- Exact evidence types and review provider are implementation decisions unless later specified.


## 5. Ranking

- Verification level is a ranking signal.

- Verification should improve trust/ranking without automatically making every unverified dog invisible unless configured as a hard eligibility rule.


## 6. User Experience

- Show current verification level clearly.

- Do not imply that a verified tier guarantees unrelated claims.

- Rejected verification should explain next steps without exposing internal moderation details.
