# Doggy Style Documentation

This directory contains the approved product, UX, and technical specifications.

## Authority order

1. Product decisions explicitly confirmed by the project owner.
2. The relevant numbered product/technical specification.
3. Wireframe specifications and wireframes for presentation/interaction details.
4. Implementation conventions in `AGENTS.md`.
5. If a requirement is genuinely missing, stop and ask rather than inventing a business rule.

The documentation describes the intended product. Supabase migrations and application code are the implementation of these specifications; they are not substitutes for the specifications.
