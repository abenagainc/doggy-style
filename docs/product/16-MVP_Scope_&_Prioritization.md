# Document 16 — MVP Scope & Prioritization

Doggy Style — Product Architecture | Draft v0.2

- MVP validates owner registration → dog setup → discovery → interest → mutual connection → free-form conversation → proceeding.

- P0: authentication, owner verification foundation, dog creation/management, four mandatory fields, progressive completion, availability, matching preferences, Tinder-style discovery, Pass, Interested, Strong Interest, received interests, connections, free-form chat, report/block, tiered verification foundation, distance, review passed, edit preferences.

- P1: richer verification workflows, notifications, advanced profile sections, moderation tooling, improved ranking, expanded screening support.

- P2: payments, contracts, negotiation/transactions, customer-facing configuration, adoption, dating, auctions.

- Out of MVP: co-ownership, ownership transfer, actual payments, mandatory structured screening, external multi-tenant configuration UI.

- Future capabilities should not require rebuilding the core domain model.
