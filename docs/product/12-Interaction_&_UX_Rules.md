# Document 12 — Interaction & UX Rules

Doggy Style — Product Architecture | Draft v0.2

- Every dog-specific interaction identifies the Active Dog.

- Dog switching is globally accessible and immediately changes Discover, Interests, Connections and Messages.

- Notifications about another dog switch context before opening the destination.

- Discovery uses Tinder-style cards with explicit Pass, Interested and Strong Interest decisions.

- Strong Interest is visibly distinct and visible to the recipient.

- Chat is free-form in MVP and keeps dog-pair context visible.

- System events are visually distinct from user messages.

- Important actions receive immediate feedback; destructive actions require confirmation.

- Failed network actions provide retry behavior and preserve input where possible.

- Accessibility: do not rely on color alone for status, verification or actions.
