# Document 14 — Permissions & Roles

Doggy Style — Product Architecture | Draft v0.2

- Owner: manage account and owned dogs; set availability/preferences; discover; send interests; review interests; chat; proceed/end; report/block.

- Co-ownership: not supported in MVP.

- Moderator: review reports and safety incidents and apply moderation outcomes.

- Administrator: manage users, dogs, verification configuration, matching configuration and operational rules.

- Future roles can include adopter, rescue, bidder, seller, buyer and dating participants.

- Authorization is enforced by backend role and ownership checks, not frontend visibility alone.
