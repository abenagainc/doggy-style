Document 06 — User Flows

Doggy Style — Core User Journeys


## 1. Core Product Loop

- Create Account → Create Dog → Complete Breeding Profile → Activate Dog → Discover → View Dog → Express Interest → Mutual Interest → Connection → Conversation → Screening → Decision → Proceed or Close.


## 2. New Owner Onboarding

- Landing → Sign Up → Email/Phone Verification → Owner Profile → Create First Dog.


## 3. Create First Dog

- Basic Information → Photos → Health → Pedigree → Breeding Information → Preferences → Review → Dog Created.


## 4. Start Matching

- Dog Ready → Discover → Candidate Feed.

- The interface should make it clear that the user is discovering matches for the Active Dog.


## 5. Candidate Discovery

- Discover → Candidate → Review Candidate → Pass or Interested → Next Candidate.


## 6. Mutual Interest

- Owner A expresses interest in Dog B. Owner B expresses interest in Dog A. The system creates a Connection.


## 7. Conversation & Screening

- Connection Created → Connection Detail → Start Conversation → Questions/Information Exchange → Screening → Decision.


## 8. Proceed

- Conversation → Proceed → Confirm Intent. Both owners confirm → Proceeding.


## 9. End Connection

- Connection → End Connection → Optional Reason → Confirm → Closed.


## 10. Switch Active Dog

- Global Dog Switcher → Select Dog → Active Dog changes → Discover, Connections, and Messages update to the selected dog's context.


## 11. Add Second Dog

- More → My Dogs → Add Dog → Create/Complete Dog → Optional 'Make Active' choice.


## 12. Notifications

- Notifications identify the relevant dog and, when selected, automatically switch to the relevant dog context before opening the destination.


## 13. Report / Block

- Report is available from relevant dog, owner, and conversation contexts. Block is available as a separate owner-level action.


## 14. Key Cross-Dog Rule

- The interface must never display dog-specific activity under the wrong Active Dog. Switching dogs must update the relevant discovery, connection, and message context.
